# Wardrobe — дизайнер шкафов-купе

Одностраничный планировщик стеллажной П-образной конструкции в фрагменте комнаты
из трёх стен: центральная стена с телевизором, боковые стены, розетки.

Стек: **Vite + TypeScript (vanilla)**, рендер — инлайновый **SVG** (фасад + план сверху),
без внешних рантайм-зависимостей.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # прод-бандл в dist/ (tsc --noEmit + vite build)
```

Регрессия доменной логики (headless): открыть `/​?autotest` — в `<pre id="autotest-result">`
и `document.title` будет вывод PASS/FAIL; гоняется так:

```bash
google-chrome --headless=new --dump-dom --virtual-time-budget=8000 'http://localhost:5173/?autotest'
```

## Модель (всё в миллиметрах)

- `Project` — три стены (`left/center/right`, длина), потолок, цоколь, сетка привязки.
- `WardModule` — модуль: стена, отступ `from`, ширина/высота/глубина, `kind`
  (шкаф, полки, ящики, открытый, ниша ТВ) и **фасад как сетка рядов×ячеек**
  (дверь с петлёй, ящик, открыто, стекло, панель + цвет из палитры).
- `TvSpec` — ТВ на стене (центр X/Y, размеры); `SocketSpec` — розетки.
- Инварианты стены: модули не пересекаются; при перемещении соседи расступаются
  (`resolveAround`), при переполнении стены движение отклоняется.

## Управление

| Действие | Как |
|---|---|
| Добавить модуль | кнопка библиотеки (на активную стену) или двойной клик по стене |
| Переместить | перетаскивание корпуса (соседи/обгон) |
| Изменить ширину | синие ручки на краях выбранного модуля |
| Тип ячейки фасада | двойной клик по ячейке (циклически) или селект в панели |
| ТВ | кнопка «+ ТВ», перетаскивание; «Ниша под ТВ» — автоматическая перестройка |
| Розетки | «+ Розетка», перетаскивание; конфликт с фасадом — красная подсветка |
| Навигация | колесо — зум, перетаскивание фона — панорама, `F` — вписать |
| История | `Ctrl+Z` / `Ctrl+Shift+Z`, кнопки на тулбаре |
| Данные | автосейв в localStorage; 💾 JSON / 📂 Открыть / 🖼 PNG |
| Удалить выбранное | `Delete`, снять выбор — `Esc` |

## Структура

```
src/
  types.ts        доменная модель
  defaults.ts     пресеты модулей/фасадов, палитра, стартовый проект
  geometry.ts     mm-геометрия: раскладка фасадов, packing, снап
  validate.ts     диагностики (пересечения, ТВ, розетки, потолок)
  store.ts        состояние + история (снапшоты) + автосейв
  edit.ts         команды: add/move/resize/dup/niche/socket/cycle
  state.ts        ui-состояние, камера фасада, шина перерисовки
  views/facade.ts SVG-фасад трёх стен + drag/zoom/dblclick
  views/plan.ts   SVG-план сверху (клик-выбор)
  panels.ts       тулбар, библиотека, свойства (редактор фасада), статус
  io.ts           JSON save/open, PNG export
  autotest.ts     программный smoke-тест (?autotest)
```
