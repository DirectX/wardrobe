# Wardrobe — дизайнер шкафов-купе

Одностраничный планировщик стеллажной П-образной конструкции в фрагменте комнаты
из трёх стен: центральная стена с телевизором, боковые стены, розетки.

Стек: **Vite + TypeScript (vanilla)**, рендер — инлайновый **SVG** (фасад + план сверху),
без внешних рантайм-зависимостей.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # прод-бандл в dist/ (tsc --noEmit + vite build)
```

Регрессия доменной логики (headless): открыть `/?autotest` — в `<pre id="autotest-result">`
и `document.title` будет вывод PASS/FAIL:

```bash
google-chrome --headless=new --dump-dom --virtual-time-budget=8000 'http://localhost:5173/?autotest'
```

## Модель v2 (всё в миллиметрах)

Базовая сущность — **секция (cell)**, как в реальной мебели:

```
Project ─── стены left/center/right, потолок, цоколь, сетка
  └── WardModule — корпус на стене: from, w, h, depth, kind
        └── Cell[] — секции, Σ ширин секций = ширина модуля (инвариант, ловит валидатор)
              ├── w          — ширина секции (тягается за жёлтые границы)
              ├── facade     — null (открытая, полки видно) | дверь | ящики | панель | стекло
              ├── shelves    — число полок…
              ├── shelfPitch — …или высота одного отсека (тогда полки по ней)
              ├── drawers    — число ящиков для facade='drawer'
              └── hinge, fill
  ├── TvSpec   — ТВ на стене; за ним обязана быть открытая секция
  └── SocketSpec[] — розетки; конфликт с фасадом — предупреждение
```

`kind` модуля — только пресет начальных секций (шкаф-купе → 2+ дверцы, ящики →
стек ящиков, ниша ТВ → открытая и т.п.). Тип можно сменить в любой момент — секции пересоздадутся.

Проекты v1 (фасад-сетка рядов×ячеек) мигрируются автоматически (`migrate.ts`),
включая автосохранение и импорт JSON.

## Управление

| Действие | Как |
|---|---|
| Добавить модуль | кнопка библиотеки (на активную стену) или двойной клик по пустому месту стены |
| Переместить модуль | перетаскивание (соседи расступаются, возможен обгон) |
| Ширина модуля | синие ручки на краях (секции масштабируются пропорционально) |
| Выбрать секцию | клик по секции |
| Ширины секций | тяга жёлтых ручек на границах секций; или поле «ширина»; или «⇄» — пополам |
| + секция / − секция | кнопки в панели свойств (− отдаёт ширину соседу) |
| Фасад секции | двойной клик по секции (вкл/выкл) или селект «фасад» |
| Полки | «полок» — число; «полка, мм» — высота отсека (пустое = равно деление по числу) |
| ТВ | «+ ТВ», перетаскивание; «Ниша под ТВ» — автоматическая перестройка |
| Розетки | «+ Розетка», перетаскивание |
| Навигация | колесо — зум, перетаскивание фона — панорама, `F` — вписать |
| История | `Ctrl+Z` / `Ctrl+Shift+Z`, кнопки на тулбаре |
| Данные | автосейв localStorage; 💾 JSON / 📂 Открыть / 🖼 PNG |
| Удалить выбранное | `Delete`, снять выбор — `Esc` |

## Структура

```
src/
  types.ts        модель v2: Cell, WardModule, Project
  defaults.ts     пресеты секций по типам, палитра, стартовый проект
  migrate.ts      конвертация v1 (фасад-сетка) → v2 (секции), идемпотентна
  geometry.ts     mm-геометрия: layoutCells, полки (shelfYs), packing, снап
  validate.ts     диагностики: пересечения, Σ секций, ТВ, розетки, потолок
  store.ts        состояние + история (снапшоты) + автосейв + миграция при загрузке
  edit.ts         команды: модули (add/move/resize/dup/niche) и секции
                  (split/setCellWidth/dragCellBoundary/remove/toggleFacade)
  state.ts        ui-состояние (выбор модуля+секции), камера, шина перерисовки
  views/facade.ts SVG-фасад трёх стен: drag, ручки двух уровней, dblclick
  views/plan.ts   SVG-план сверху (клик-выбор)
  panels.ts       тулбар, библиотека, свойства (редактор секций), статус
  io.ts           JSON save/open (через migrate), PNG export
  autotest.ts     32 программные проверки (?autotest)
```
