# Wardrobe — дизайнер шкафов-купе

Одностраничный планировщик стеллажной П-образной конструкции в фрагменте комнаты
из трёх стен: центральная стена с телевизором, боковые стены, розетки.

Стек: **Vite + TypeScript (vanilla)**, рендер — инлайновый **SVG** (фасад + план сверху),
без внешних рантайм-зависимостей. Светлая тема оформления по умолчанию.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # tsc --noEmit + vite build → dist/
```

Регрессия доменной логики (headless): открыть `/?autotest` — результат PASS/FAIL
в `<pre id="autotest-result">` и `document.title`:

```bash
google-chrome --headless=new --dump-dom --virtual-time-budget=10000 'http://localhost:5173/?autotest'
```

## Модель v3 (всё в миллиметрах)

Единственный строительный блок — **модуль** (контейнер, кнопка «+ Новый модуль»): короб на стене,
внутри которого дерево нарезки произвольной глубины. Размеры детей сплита —
**абсолютные мм**: тяга перегородки меняет только два смежных проёма, остальные
полки группы стоят на месте — и во вложенных рядах тоже. Локальные правки
(тяга, толщина перегородки, общие стенки, удаление узла) подгоняют дерево
через `fitTree`: разница уходит последнему проёму ряда, нетронутые отсеки не
двигаются. Пропорциональный пересчёт (`normalizeTree`) — только при ресайзе
контейнера целиком:

```
WardModule — короб: wall, from, w, h, depth
  └── root: BoxNode — рекурсивное дерево
        ├── SplitNode { dir: 'v'|'h', t: толщина перегородки, children: [{size, node}] }
        │     (children[].size — абсолютные мм вдоль оси)
        └── LeafNode  { face } — отсек:
              ├── open    — ниша (полки: число ИЛИ шаг «shelfPitch»), фасад отсутствует
              ├── door    — дверца (петля, цвет, опц. стекло)
              ├── drawers — стек выдвижных ящиков (число, цвет)
              └── panel   — глухая панель
```

- «Шкаф-купе», «Полки», «Ящики», «Ниша ТВ» как виды модулей **убраны**: всё
  собирается нарезкой одного контейнера. Размер детей сплита — относительный
  (`size`), layout нормализует их под короб, поэтому ресайз контейнера
  пропорционален и никогда не ломает инвариант «дети + перегородки = нутро».
- `size` в дереве хранится как есть; при тяге перегородки меняется только пара
  соседей (`dragDivider`), остальные дети не едут.

**Общие стенки**: у контейнера флаги `leftShared/rightShared`. Модули, вставшие
вплотную, получают общую стенку автоматически. Физически это одна панель 18 мм
на стык: в **раскрое она учитывается один раз — за левым модулем** («Стенка
правая (общая с соседом)»), правый модуль свою левую стенку не кроит. Половинки
по 9 мм — только модель внутреннего пространства (interiorBox), не деталь.
Флаги переключаются вручную в свойствах; при разъезде модулей общие стенки
снимаются автоматически. Толщина своей стенки — 18 мм (крышка/дно — всегда 18).

**Углы (симметричные)**: контейнер, задвинутый в угол на любой стене, резервирует
на смежной стене зону своей глубины (`cornerZones → {start, end}`): у боковой
стены зона одна (от угла с центральной), у центральной — две (левый и правый углы).
Зона работает в обе стороны: добавление/перетаскивание не пускает, ручной наезд
ловит валидатор, зона заштрихована на фасаде. Левая стена на фасаде зеркалится
(угол — справа, как при взгляде из комнаты).

Проекты v1 (фасад-сетка), v2 (плоские секции) и v3 (дерево с относительными
весами) мигрируются автоматически (`migrate.ts`): относительные размеры
пересчитываются в мм через `normalizeTree`, общие стенки выставляются по
фактическим стыкам. Автосохранение из старых ключей localStorage и импорт JSON.

## Управление

| Действие | Как |
|---|---|
| Поставить модуль | «+ Новый модуль» в библиотеке (на активную стену) или двойной клик по стене |
| Переместить / ширина | перетаскивание корпуса / синие ручки по краям |
| Выбрать узел | клик по отсеку/перегородке на чертеже или по строке **дерева структуры** (правая панель сверху): выбирается ячейка или секция целиком |
| Разделить отсек | левая панель «Нарезка»: «⊢ Вертикально» / «⊤ Горизонтально» (пополам) |
| Тянуть перегородку | жёлтые грифы на чертеже (v — col-resize, h — row-resize); двигаются **только два смежных проёма**; **привязка** по всей стене: к перегородкам всех модулей (того же направления), к линиям полок открытых ниш (h) и к **центрам модулей и вложенных секций** (v — симметричное деление). Допуск ≈ 8 экранных px при любом зуме (не мельче grid/2), при срабатывании — жёлтый пунктир |
| Общие стенки | автоматически при установке вплотную; чекбоксы «лев./прав. стенка общая» в свойствах модуля |
| Тип отсека | свойства справа: селект «отсек» (Ниша/Дверца/**Ящик**/Панель) + «⇄ Ниша/дверца/ящик» — цикл двойным кликом: ниша → дверца → выдвижной ящик (число подбирается по высоте ~240 мм/шт) → ниша; «± полка» для ниши |
| Секция целиком | свойства секции: толщина перегородки, «⇄ Повернуть нарезку» (v↔h), массовое лицо всех вложенных отсеков, «✕ Убрать узел» удаляет секцию со всеми детьми |
| Купе | «◫ Купе-двери» (в нарезке слева или в свойствах секции) — раздвижные створки поверх всей секции: 2–6 шт., цвет, стекло, нахлёст 25 мм; створки кликабельны (выбирают секцию); ТВ/розетки за створками — ошибка/предупреждение |
| Перекрытия | перекрывающиеся фрагменты фасада (купе поверх дверец, соседние створки, наехавшие корпуса) подсвечиваются **красной штриховкой с подписью «⚠ перекрытие»** прямо на чертеже и в PDF; список — в статус-строке (клик выделяет модуль) |
| Полки ниши | «полок» (0–20, шаг 1), «шаг полки» в мм, или «± полка» в тулбаре |
| Перегородка | «перегородка, мм» (толщина `t` у родительского сплита) |
| Убрать отсек | «✕ Убрать отсек» — размер уходит соседу, сплит схлопывается |
| ТВ | «+ ТВ», перетаскивание; «Ниша под ТВ» — вырезать контейнер с нишей |
| Розетки | «+ Розетка», перетаскивание; за фасадом — предупреждение |
| Навигация | колесо — зум, фон — панорама, `F` — вписать |
| История | `Ctrl+Z` / `Ctrl+Shift+Z` |
| Данные | автосейв localStorage; 💾 JSON / 📂 Открыть / 🖼 PNG / ⬇ CSV (спецификация раскроя для Excel, UTF-8 BOM) |
| **PDF-отчёт** | 🖨 PDF → печатное окно: фасад с размерными линиями **от грани плиты до грани** (общая плита стыка — отдельным размером 18 мм, без отсчёта от середины), план сверху с глубинами, спецификация раскроя (приоритет — горизонтальные перегородки на полную ширину). В диалоге печати — «Сохранить как PDF», A4 альбомная |
| Прочее | `Delete` — удалить выбранное, `Esc` — снять выбор |

## Структура

```
src/
  types.ts        модель v3: BoxNode (split/leaf), LeafFace, Project
  defaults.ts     билдеры leaf/splitV/splitH, палитра, стартовый проект
  migrate.ts      v1/v2 → v3, идемпотентна
  geometry.ts     layoutModule (абсолютные мм, дрейф → последний проём),
                  fitTree (локальные правки) / normalizeTree (ресайз), interiorBox
                  (общие стенки: 9 мм на стык), cornerZones, snap по всей стене
                  (dividerSnapCandidates + зум-зависимый snapTolerance),
                  findOverlapRegions (перекрытия фасадов), packing
  validate.ts     диагностики: углы, пересечения, ТВ за фасадом, розетки, потолок
  store.ts        состояние + история + автосейв (v3 ключ, legacy-цепочка)
  edit.ts         контейнеры (add/move/resize/dup) и дерево
                  (splitLeaf/removeLeaf/dragDivider/setFace/toggleFace/setDividerT)
  state.ts        выбор модуля + path отсека, камера, шина перерисовки
  views/facade.ts SVG-фасад: рекурсивный рендер дерева, зеркала, грифы перегородок
  views/plan.ts   SVG-план сверху (окрас по глубине)
  panels.ts       тулбар, библиотека + инструменты нарезки, дерево структуры,
                  свойства узла (лист/секция), статус
  bom.ts          спецификация раскроя: корпус, перегородки (h — на полную
                  ширину проёма, v — между ними), полки, фасады, купе;
                  выдвижной ящик — стандартная конструкция на шариковых
                  направляющих: фасад, 2 царги, 2 стенки короба, дно ДВП 3.2,
                  зазоры −12.7/сторону, −10 сверху, −15 снизу и от задней
                  стенки, длина направляющей из стандарта 250…500;
                  bomToCsv → CSV
  print.ts        печатный отчёт: SVG-фасад с размерами от граней плит
                  (moduleDimRefs — общая плита отдельным размером), план, BOM → PDF
  io.ts           JSON save/open (через migrate), PNG export
  autotest.ts     144 проверки: абсолютная тяга, общие стенки (в т.ч. одна
                  плита на стык в раскрое), привязки, купе, оверлей перекрытий,
                  цикл лица, BOM ящика, CSV, печать (?autotest)
```
